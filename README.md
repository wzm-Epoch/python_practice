# Python Practice

这是一个用于记录个人 Python 学习与练习代码的仓库，内容包含 Python 基础、进阶语法、算法、网络编程和网页爬虫等示例。

## 学习内容

- Python 基础练习与简单项目
- 面向对象、继承和多态
- 闭包、装饰器与深浅拷贝
- 迭代器、生成器与正则表达式
- 递归、排序与查找算法
- 多进程、多线程与 Socket 网络编程
- 使用 `requests`、`lxml` 进行网页数据抓取

## 使用方法

请先安装 Python 3，然后克隆并进入项目目录：

```bash
git clone https://github.com/wzm-Epoch/python_practice.git
cd python_practice
```

选择任意示例运行，例如：

```bash
python "九九乘法表.py"
```

大部分示例仅使用 Python 标准库。运行爬虫相关示例时，可能需要额外安装依赖：

```bash
pip install requests lxml
```
